Entry for the make.fun competition **One-Sentence Absurd Invention Pitch**
(`u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a`).

`main.ts` writes one sentence — a ridiculous invention fixing a tiny everyday
annoyance — to `/output/entry.txt`:

> The Jar Lid Negotiator is a jar lid that loosens itself after a short
> staring contest, because it respects anyone stubborn enough to glare at a
> pickle jar for a full minute.

Run with Node 22: `node main.ts`.
